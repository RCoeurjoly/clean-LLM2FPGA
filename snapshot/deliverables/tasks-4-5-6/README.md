# Tasks 6, 4 and 5 review package

This is the self-contained, compiler-generated TinyStories deliverable for
[project plan v2](../../docs/project-plan_v2.org). It is on the unmerged
`deliverables/tasks_6_4_5` branch, based on `main` at `b6dc8ab`. The curated
source comes from `compiler-lab-llm2fpga` commit `37b2d6c`; see the
[source inventory](SOURCES.md). The nested [flake](flake.nix) pins the model
package, Calyx and open XC7 tools. Kev-gpt supplies model-package data and
reference context, **not accelerator RTL**. The accelerator is generated by
the compiler pipeline; this implementation and packaging are LLM-assisted.

From the repository root, build the three reviewer gates with Nix:

```sh
nix build --no-link --print-out-paths ./deliverables/tasks-4-5-6#task6-bram-bitstream
nix build --no-link --print-out-paths ./deliverables/tasks-4-5-6#task4-board-evidence
nix build --no-link --print-out-paths ./deliverables/tasks-4-5-6#task5-tinystories-family-stage-matrix
```

Task 6 rebuilt the full TinyStories-1M compiler/BRAM design, a legal zero-
overuse route at the unchanged 30 MHz constraint, and a bitstream with the
same decoded configuration as the archived board-tested image. The raw `.bit`
headers differ. The accepted mapping uses 813 RAMB36, 89 RAMB18 and 190 DSP;
see the [fit audit](docs/results/2026-09-29-task6-fit-audit.md).

Task 4 rechecks [archived raw board evidence](artifacts/task4/full16-board-2026-09-29/README.md):
three independent FPGA SRAM programs produced the exact fixed-prompt,
16-token continuation in about 66.4 seconds each. This import **did not
program the board**. See the [hardware closure](docs/results/2026-10-01-task4-fpga-integration-closure.md).

Task 5 builds the same family compiler path for pinned TinyStories 1M, 3M,
8M, 28M and 33M checkpoints. All five generated-RTL first-token simulations
matched their model-specific fixed-point oracles. A separate 1M, two-run
autonomous-feedback simulation produced the exact frozen 16-token continuation:

```sh
nix build --no-link --print-out-paths ./deliverables/tasks-4-5-6#task5-tinystories-1M-16token-simulation
```

The [current stage matrix](docs/results/2026-10-05-tasks-4-5-6-review-verification.md)
records source-rebuilt 1M/3M/8M synthesis. The 3M and 8M mappings exceed the
board's BRAM36 capacity; the 28M/33M synthesis failures are **archived donor
observations**, with no current synthesis derivation or resource count. Task 5
does not claim route, timing or board inference for those larger models. The
1M family synthesis numbers are a first-token scaling artifact, not the
accepted full-16-token YPCB mapping.

The accepted board demonstration uses a frozen four-token prompt, not a
general-prompt CLI. BRAM/DSP internal timing coverage is incomplete despite
the legal route and successful archived board runs. PCIe, DDR3 and wider-model
board inference are outside this package. For commands, observed outputs and
limits, see the [review verification report](docs/results/2026-10-05-tasks-4-5-6-review-verification.md).
