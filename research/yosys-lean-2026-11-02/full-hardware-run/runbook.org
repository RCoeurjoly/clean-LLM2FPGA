** Run the branch

Branch at the generic =direct-prepared= checkpoint, before DSP/BRAM
technology mapping. Preserve the generic memories. The additional stages
are recorded as individual Yosys scripts and measured commands:

1. Read production-checked generic RTLIL. Lower only the 336 one-word
   memories with =memory_map t:$mem_v2 r:SIZE=1 %i=, assert that 555
   memories remain, check, and write the canonical RTLIL/metadata JSON.
2. Run the pinned importer's preflight over that metadata.
3. Normalize clocks with =clk2fflogic -nolower -nopeepopt=,
   =memory_nordff=, =opt_clean= and =setundef -undriven -anyseq=.
4. Use the importer's native Yosys =expose= plan so arbitrary sources
   become explicit input ports. Retain named-state metadata.
5. Export FunctionalIR SMT-LIB and matching JSON from the same final
   normalized design.
6. Stream those artifacts through the pinned =xiangshan2Lean= helpers.
7. Generate its typed table model, compile the Lean interpreter and
   generated model, and check the reported node/interface counts.

** Transfer projection for large initialization tails

The native export completed in 352.63 seconds at 15,950,588 KiB peak
resident memory. It produced full matching JSON and a 10,879,385,560-byte
SMT file. Most of that SMT file consists of per-address initialization
assertions, which the pinned importer syntax-checks but discards; its
initial-state constraints come from JSON instead.

[[file:transfer_projection.py][transfer_projection.py]] retains the exact 632,948,862-byte prefix
containing the three records, Pair datatype and sole transfer function.
It stops at the expected native initial-state declaration and checks
the source snapshot/ordering. The complete native export remains intact.
The [[file:yosys-v0.62-smtlib.cc::258][pinned native serializer source]] establishes that the complete
transfer precedes that declaration and only initialization assertions
follow it for our selected single module. The saved source matches the
actual package and official Git blob; see [[file:serializer-source.json][source provenance]].

The unchanged upstream importer then reads the projected transfer and
restores all known/unknown initialization bits from matching metadata.
No initial condition is replaced with zero or removed from that metadata.
On the production memory control, the full and projected serializations
produce identical imported program nodes and initial constraints:
[[file:projection-control.json][projection control result]]. This is a producer-side projection under
the pinned serializer contract, not a generic SMT-LIB transformation.

The first full import worker was stopped before parsing the redundant
tail and restarted with this projection. Its interrupted attempt is
retained with =.before-projection= suffixes. This interruption is not an
importer semantic failure. The subsequent small projection guard failure
on a newline-formatted =define-fun= was caught by the control, corrected,
and the equality control passed before the current full import restarted.

The small memory control regenerates its typed table, compiles the
interpreter and model, and runs both Lean and Icarus with:

* Progress and meaning of success

** First full-model importer gap: one-word memories

The first complete streaming preflight inspected all 913,942 cells in
211.74 seconds. It reported 336 rejected =$mem_v2= cells. Every rejected
cell matches a =SIZE=1= instance in the original generated SV; there
were no other diagnostic families. See [[file:preflight.json.initial][original preflight]],
[[file:scalar-memory-coverage.json][exact source-instance coverage]], and [[file:01-preflight.resources.txt.initial][measured resources]].

The unmodified importer requires at least two words per memory. A minimal
[[file:scalar-reproducer.sv][production-memory reproducer]] containing one scalar memory and a
16-word memory demonstrates the rejection. Native Yosys =memory_map=
restricted to the scalar memory makes preflight pass, retains the
16-word memory, and preserves the known scalar initialization bits.
The before/after RTLs agree on a concrete reset/write/read/hold trace.
Evidence: [[file:scalar-reproducer.ys][normalization script]], [[file:scalar-normalization-result.json][structural/init results]],
[[file:scalar-tb.sv][trace testbench]], and [[file:scalar-trace.log][successful trace]]. No importer condition was
disabled or relaxed. The trusted Yosys normalization now lowers exactly
those 336 words to registers, retaining every larger memory.

The first attempt's scripts, reports and logs are retained with =.initial=
suffixes. The original full JSON is retained under =/tmp= as
=before.initial.json=. The revised full-model path passed the complete
preflight in 212.20 seconds with zero remaining diagnostics, 28,372
register cells and 555 memories. Its peak resident memory was about
516 MiB. The same pinned importer checks ran; none was bypassed.
