* Result

The strongest direct netlist result is deepai-org/loom: its Python adapter reads actual Yosys JSON schema and Lean parses and lowers the resulting neutral IR into executable hardware semantics. The adapter and Yosys remain untrusted, and its source requires independent equivalence evidence.

Restricted SystemVerilog import routes exist in lean-surfaces, LEAP and circuitprover-sv. Sparkle has a real parser but the source still skips failed always blocks and missing modules and can emit admitted proofs. All 18 inspected parser-bearing forks retained the three principal inherited gaps. HDLean's proved SV parser reads its own rigid emitted grammar; VerilLean supplies modified Lean-embedded syntax.

Lean-surfaces has real hierarchical SPICE parsing and circuit semantics, but a working bridge from Yosys digital SPICE output was not established. No source-verified Lean importer was found for BLIF/EBLIF, EDIF, JNY, Intersynth, SimpleC, Functional C++, CXXRTL or Yosys connection tables within this bounded audit. The xiangshan2Lean runtime table is a different format from Yosys write_table.
